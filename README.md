# selimcakar.github.io

Personal portfolio — static, modular, zero dependencies.

**Live:** [www.selimcakar.com](https://www.selimcakar.com)

## Stack

- HTML5, CSS3, Vanilla JS (ES Modules)
- Canvas particle system, typing animation, glassmorphism UI
- Hosted on GitHub Pages

## Structure

```
index.html        — Page markup
css/style.css     — Styles and design tokens
js/main.js        — Entry point
js/loader.js      — Loading screen
js/particles.js   — Particle background
js/typing.js      — Typing effect
js/scroll-reveal.js — Scroll animations
```
